## Loan form (copy per piece, per student, per cohort, blanks only)
- Piece and code, open-hardware status, condition at loan (photo filed, file path), cable and accessories listed, hardware gate passed before loan (output filed).
- Loan period (date-order only, no calendar date locked by this template), return gate required, custody holder (role, not a personal name in any published copy).
- Condition at return (photo filed), damage / loss / theft, if any, stated plainly with method and error, and a correction / replacement plan filed. A loaned piece is not returned until its return gate passes.
- Insurance note: personal equipment is the student's own responsibility unless a filed loan record states otherwise; loaned course equipment is covered only as stated in a filed insurance record, never by assertion.

## Custody rule
Own targets secured at close, loaned pieces secured at close, templates and recordings deleted where required, deletion log filed. A piece that is lost, damaged, or unreturned is filed as lost / damaged / unreturned, with a Dean review, and is never filed as returned by assertion.
