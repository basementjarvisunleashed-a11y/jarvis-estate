## Spine and hard rules, every day, no exceptions
SEE → DOCUMENT → LOG → PREVENT. Controlled lab / own venues only. Own devices, own tags, own networks, own targets only. Consenting adults only. Face work: consenting adults, lab only, defensive education, templates deleted after the exercise, deletion log filed — never family, never son, never strangers, never real-world surveillance or deployment. Radio transmit only on own authorised frequencies. Drone only in a safe, controlled area, Transport Canada checklist first. Lasers Class 1 only. Evidence filed the same day it is made. A day does not close with an unfiled log. A failed gate is logged as failed, with method and error, and resubmitted — never hidden, never marked passed.

## Weekly rhythm, template (order only, no dates, no clock times)
- Lab days: 3 per week, draft.
- Evidence / homework day: 1 per week, draft.
- Audit / inspection / lecture day: 1 per week, draft.
- Buffer days: catch-up only, no new teardown, finish logs, resubmit failed gates. Buffer principle, draft: at least 1 buffer / catch-up day per teaching week, plus 1 buffer week per block — exact count locks only when year and holiday calendar lock.
- Farm / airfield days: replace a lab day, same daily structure, plus venue and weather checks.
- Capstone days: replace a lab day in the mid-course and final capstone blocks.

## Daily blocks, in order (no clock times locked)
Lab day: opening brief (safety, consent, scope, hardware gate) → tool check (Kali, REA, stacks for the day, versions recorded) → lab setup (own target, isolated own network, measurement tools, ground truth) → morning test block → midday review → afternoon test / re-test after hardening → evidence pack block (Graphify update: flaw, device, method, defence linked) → debrief (one finding per student, one inspection note, one correction) → close (tidy, targets secured, templates/recordings deleted where required, deletion log filed, next day's hardware gate checked).
Homework day: review week's logs and failed gates → reading (lecture notes: GenOffice written, VoiceStudio narrated) → teardown write-up (one own target, REA) → evidence log completion → hardening answer with re-test plan → Graphify block → close, pack filed.
Audit / inspection / lecture day: audit scope (areas in scope, areas out of scope with reason) → weekly lab inspection → audit pass (network, web, wireless, RFID, Bluetooth, SDR, chips, vision, mesh, as required) → lecture from live lab evidence only (every claim traces to a log entry) → defence brief draft → close, findings and corrections filed.
Farm / airfield day: venue and weather check first (wind, visibility, rain, heat, storm, snow; no flight in snow or high wind) → Transport Canada checklist for drone days → venue safety brief → setup with ground truth markers → test blocks as a lab day, with range, loss, and error measurements → evidence pack (maps, range logs, flight logs, mesh logs, night fusion maps, ground truth tables) → close, venue inspection note filed.
Capstone day: scope and team roles, scoring evidence quality first, then completeness, then clarity, speed alone does not win → scan own estate → break own target → defend and re-test → report (evidence pack, written report, narrated summary, defence brief, team score sheet) → defence verified by re-measurement → close, full pack filed.

## Roles, rotating daily
Operator (runs the test, records command and output), Recorder (owns the evidence log, file paths, measurements, errors), Auditor (checks gates, inspects logs, verifies re-measurement). Roles rotate daily. No student audits their own log alone.

## Audits, inspections, assessment
- Audits: 12 monthly, 4 quarterly, 1 final, draft counts from the year draft — exact schedule locks with the cohort.
- Inspections: weekly lab inspections, monthly venue inspections.
- Assessment: evidence pack 40%, written report (GenOffice) 25%, narrated summary (VoiceStudio) 15%, defence brief and capstone defence 20%. Failed gate resubmitted until it passes. No mark for fabricated, incomplete, or unverifiable results.
- Holidays and weather, Toronto / Ontario only, rules not dates: no mandatory teaching on Ontario statutory holidays; no mandatory teaching for a student observing a religious holiday, catch-up on buffer, no penalty. Exact holiday dates lock with the cohort. Weather: winter indoor primarily; spring lab + farm + airfield, rain fallback indoor; summer farm + airfield, heat / storm fallback indoor, hydration, shade, storm-stop in the safety brief; fall lab + farm + airfield with fallback, final evidence moves indoors as days shorten; December indoor primarily.
