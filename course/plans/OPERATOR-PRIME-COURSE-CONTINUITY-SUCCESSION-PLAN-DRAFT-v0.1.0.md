## Continuity, in order
1. Archive first: every course file, versioned, indexed, never deleted, on GitHub (via the Publishing House), in Dropbox, and in the local course tree, so no single surface is the only copy.
2. Feed second: the Dean's daily / weekly / monthly feed is filed per course, per cohort, so a professor can pick up the next feed without improvisation.
3. Gate third: no lab, venue day, or capstone runs with an open insurance, safety, consent, or scope gap in its own checklist, whatever the staffing situation.
4. Pause fourth: if the Dean or the professor is unavailable, the course pauses at the last passed gate, with a filed pause notice, and resumes only through a Dean-approved catch-up plan, starting from the last passed gate, never from an unpassed gate by assertion.
