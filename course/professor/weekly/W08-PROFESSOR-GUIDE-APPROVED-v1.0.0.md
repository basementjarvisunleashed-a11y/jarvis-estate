## The PhD-level standard in this guide

A claim in this course is doctoral-standard only when it meets all five tests, and the professor must hold every one of them, every week:

1. **Defined:** every load-bearing term is defined exactly as taught, with its source stated.
2. **Reproducible:** the method is written so another operator, on the same own devices and own targets, can repeat it and get the same measurement, or a stated reason why not.
3. **Falsifiable:** the claim states what measurement would disprove it.
4. **Audited:** the evidence pack, the gate, and any re-measurement are filed, indexed, and versioned — never overwritten, never deleted.
5. **Defended by re-measurement:** a challenged claim is answered with a new measurement, not with a louder restatement.

If a student's work fails any test, the professor marks that failure plainly, requires re-measurement, and records the gap. That is not harshness; it is the course.

## Teaching the week, day by day

### Lab days (Days 1–3) — how to teach them

- **Open** each day with the exact definition that carries the day, and the day's measurement goal.
- **Demonstrate once,** narrating method and checks, then hand the work to the students and step back. Correct method; do not supply results.
- **Walk the room** for the five common errors (definition drift, measurement without method, tool output as conclusion, hidden failure, wrong target). Name each error when you see it, in the moment, kindly and precisely.
- **Close** each day with the failure log: what broke, what was re-measured, what is still open. File the day's evidence before anyone leaves.

### Homework day (Day 4) — how to teach and mark it

- Set the homework from Weekly Assignment Pack W08: the student writes L8 in their own words, names the strongest and weakest evidence, and asks one real question.
- Mark homework for evidence quality: is the method repeatable from the writing alone? Is the weakest evidence named honestly? Is the question answerable by a measurement?
- Return one precise feedback note per student: one strength, one gap, one re-measurement that would close it. Never return a grade without that note.

### Audit day (Day 5) — how to run it

- Run the weekly lab inspection (benches, power, storage, device custody, evidence filing) from the Venue Inspection Pack and the Hardware Gate Checklist Pack.
- Review every evidence pack against the gate rule, in the students' presence where it teaches them: no pass on assertion.
- Carry every open thread forward, in writing, to Week 09 (or, for Week 52, to the year rollup). An open thread that is not written down is a thread dropped.

## Pitfalls specific to this week

- Teaching the lab as a demonstration the students watch, rather than work they run.
- Accepting a smooth result with no filed measurement, because it looked right.
- Letting a strong student carry a weak student's evidence pack — every pack is individual, even in team work.
- Forgetting the rotating roles: a student who never audits never learns to audit.
