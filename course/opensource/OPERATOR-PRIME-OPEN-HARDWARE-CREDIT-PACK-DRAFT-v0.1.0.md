## Credit rule, per piece
Every hardware piece used in the course is credited, in the course index and in the lab that uses it, with: piece name and code, vendor / project name as published by that vendor / project, open-hardware status as verified at purchase (open schematics / open documentation published, or software-only / partial openness stated plainly), and licence as filed by that vendor / project, where filed. A piece with no filed licence is credited by name and project only, never by an invented licence.
