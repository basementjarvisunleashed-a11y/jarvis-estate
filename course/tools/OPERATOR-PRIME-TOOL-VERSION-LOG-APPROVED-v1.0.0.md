## Log rule
Record tool, version, command, output, and error for every tool used in every lab, every day. A tool log with a missing version is an incomplete log. A tool log with an invented version is a failed log.

## Per-tool entry (copy per tool per cohort)
- Tool / stack name and family, version recorded, date-order recorded (no calendar date locked by this template).
- Command used to check version, output filed, hash recorded where applicable.
- Self-test on own target only, result filed, error filed.
- Change log: if a tool version changes mid-course, file the old version, the new version, the reason, and the re-test result for every lab that used the tool. Never overwrite the old entry.
