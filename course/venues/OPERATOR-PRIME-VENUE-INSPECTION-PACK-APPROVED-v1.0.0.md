## Inspection rhythm (template, no dates locked)
Weekly lab inspections, monthly venue inspections. An inspection that finds a failed check files it as failed, with method and correction, and a re-inspection date-order (not a calendar date locked by this pack).

## Indoor lab inspection (copy per inspection)
- Own targets only, isolated own network, hardware gates filed, logs filed, evidence packs filed, deletion logs filed, safety checklists filed, targets secured at close.
- Tool versions recorded, Kali / REA / stacks for the week recorded, ground truth tools present (tape measure, known points).

## Airfield inspection (copy per inspection, drone / spectrum / mesh range days)
- Venue boundaries stated, own targets only, no public or neighbour targets.
- Transport Canada checklist filed before any flight, wind / visibility gates passed, no flight in snow or high wind, storm-stop brief given.
- Range, loss, and error measurements filed for mesh, drone, and spectrum tests. Flight logs filed. Venue tidied, own targets secured at close.

## Farm inspection (copy per inspection, rover / mesh resilience / night fusion / LiDAR days)
- Venue boundaries stated, own targets only, no public or neighbour targets.
- Night fusion: near-IR, thermal, LiDAR, and motion recorded in parallel, presence map filed, blind-spot map filed, no identity attempted.
- Rover course with ground truth markers, obstacle log filed, mesh command and response log filed.
- Weather check filed first (rain, heat, storm, snow as applicable), fallback indoor plan stated, hydration / shade / storm-stop in the safety brief where applicable.

## Weather gates, Toronto / Ontario only (rules, not dates)
Winter: indoor primarily, airfield only with Transport Canada + wind / visibility gates. Spring: lab + farm + airfield, rain fallback indoor. Summer: farm + airfield for big experiments, heat / storm fallback indoor. Fall: lab + farm + airfield with fallback, final evidence moves indoors as days shorten. December: indoor primarily.
