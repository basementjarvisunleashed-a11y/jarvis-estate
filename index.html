What the estate does

Roles own durable jobs. Memory holds identity and method. Live systems hold the numbers. A fluent status line is not proof.

Roles, not a monolith

Nine worker bots, each with a persona, under a chief of staff. Eight skill playbooks remain the written methods. Duties do not cross.

Live sources of truth

Scores, prices, schedules, and account states are re-read from the system that owns them. Memory does not invent current numbers.

Evidence over reassurance

Consequential work returns an artifact plus sources, changes, tests, approvals, and the gaps that are still open.

Approval, then action

The system prepares what is reversible and stops before anything is sent, spent, published, or deleted.

Download and install

Windows 10 or 11. An NVIDIA GPU is optional; the reference run used an RTX 2060 6GB. The full guide is local-jarvis/README.md. Router v2.2, the 50 second budget, the 60 second client wait, ComfyUI v0.43.0, and freellmapi are on the owner's laptop. freellmapi is the fallback only. This installer does not add them.

  1. 1 Install the prerequisites

    Python 3.13, Ollama, and the two models named in the guide. VLC and Piper are in the same document. VoiceMeeter and Node are optional.

  2. 2 Run the installer

    From local-jarvis/:

    powershell -ExecutionPolicy Bypass -File .\install.ps1

    install.ps1 checks prerequisites, creates C:\Jarvis\venv, and installs both requirements files. It does not register scheduled tasks unless you pass -RegisterTasks.

  3. 3 Set secrets on the machine

    The repository ships placeholders only (CHANGE_ME, <user>). Set the VLC password and the Windows account locally. Do not commit them.

  4. 4 Start it yourself

    py -3.13 C:\Jarvis\orchestrator.py, then open http://localhost:8080. The voice loop is a manual command. It is not a login item.

  5. 5 Enroll, then calibrate

    Five takes of the wake phrase. Treat 0.45 as a starting point. Score your own voice, your voice across the room, and an unknown voice before you change the number.
