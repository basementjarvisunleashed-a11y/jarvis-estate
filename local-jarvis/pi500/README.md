# Raspberry Pi 500+ rig

The second bench machine. **Ordered and paid for by his secretary
2026-11-05, on its way for delivery.** Its role is still to be decided
— it is NOT a replacement for the Apple TV target, and the Apple TV
project comes first.

| File | What it is |
|---|---|
| `pi500-top10.md` | The top 10 things to start doing with the rig: Kali always-on, REA with its little Qwen engine, the Apple TV 3 command centre, the house network map, firmware dumps, serial consoles, Pi-hole, Home Assistant, the portable cyberdeck, the dashboard 24/7. |
| `pi500-software-stack.md` | The full software stack on Kali ARM64: base, REA core (Ghidra, radare2, REA agents, QEMU, Binwalk), network stack (nmap, Wireshark, Metasploit, Burp), the Jarvis layer (dashboard, NFS/TFTP, Pi-hole, Home Assistant, Jellyfin), the hardware-interfacing stack, and the honest limits (no IDA Pro, no GPU hashcat, small LLMs only). |
| `pi500-accessories.md` | The complete accessories sweep (PiShop.ca prices, verified 2026-11-05): the Desktop Kit route at $868.01 before shipping, plus the Samsung 990 PRO 2TB from Amazon.ca. The 7" screen IS included in this project; the REA bench list is a separate project. |

The rig: 2.4 GHz quad-core Cortex-A76 ARM64, 16 GB RAM, 2 TB NVMe
(Samsung 990 PRO, replacing the 256 GB), dual micro-HDMI (dual 4Kp60),
40-pin GPIO. Kali Linux runs everything from the 2 TB drive; Pi OS
stays on the 64 GB card as rescue only.
