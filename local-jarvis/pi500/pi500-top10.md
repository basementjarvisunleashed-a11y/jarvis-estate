# Top 10 Things to Start Doing with the Pi 500+ Rig

**Status: the plan is a GO — ordered by HgX's secretary 2026-11-05, paid, on its way for delivery.**

## 1. Boot Kali on the 2TB — and leave it on
Swap the 256GB for the Samsung 990 PRO 2TB, install Kali Linux ARM64, and run it always-on. Pi OS stays on the 64GB card as rescue only. The foundation everything else stands on.

## 2. Stand up REA with its little Qwen engine
rea-agents + Ollama + Qwen2.5-3B-Instruct abliterated — REA gets a local brain that never leaves the house. Short, sharp jobs: naming functions, reading disassembly, summarising firmware, drafting Ghidra scripts, tool-calling.

## 3. Make it the Apple TV 3 command centre
NFS/TFTP server serving the ATV3's Kali rootfs over Ethernet, kernel builds for the box, the Pico dongle plugged into USB for checkm8, and the Jarvis dashboard on the 7" LCD showing campaign status.

## 4. Map the whole house network
nmap + Wireshark: every device, every open port, and what the locks, cameras and TV actually say on the wire. The inventory the whole takeover programme runs on.

## 5. Dump firmware off the boards
Bus Pirate + Logic Sniffer into the USB 3.0 ports, pulling firmware out of the DVD players, Lorex cameras and TV boards — then Ghidra takes it apart with 16GB of RAM behind it.

## 6. Open serial consoles into the hidden command lines
The Waveshare USB-to-serial converter + minicom: UART pads on TVs, cameras and routers become a live command line. The doorway into every locked box.

## 7. Run Pi-hole house-wide
DNS-level ad and tracker blocking for every device in the house — phones, TVs, tablets, all of it, from the keyboard.

## 8. Stand up Home Assistant — the takeover hub
Smart-home control under one dashboard: the smart locks, the Samsung TV, the Lorex cameras (ONVIF). The house answering to one screen.

## 9. Build the portable Kali cyberdeck
CYBERDECK HAT on the GPIO header (plus a small display HAT later) turns the keyboard into a standalone hacking deck. Carry it to the target, plug into the TV's HDMI, and work where the target sits.

## 10. Run the Jarvis dashboard 24/7 — and let it rest in style
The always-on dashboard on the 7" LCD and the big screens: campaign status, network map, REA findings, house devices. And when the work is done — Jellyfin/Kodi media centre on dual 4K and RetroPie games. The machine earns its rest.
