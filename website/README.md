# Website

The J.A.R.V.I.S. Hub — the public site for the white papers and the build-out
chronicle — as a single self-contained `index.html`.

- **Source of truth:** the `j-a-r-v-i-s-hub` web artifact (Release Bot's
  publishing office). This file is an export of its last verified build.
- **Publishing:** push this directory to GitHub and enable GitHub Pages on it
  (or serve `index.html` from any static host) to publish the site later.
- **Updates:** the site is edited via the publishing office; re-export and
  replace this file when a new verified build lands. Never hand-edit it here —
  the artifact is canonical.
