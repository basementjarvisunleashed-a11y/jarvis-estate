Download and install

Kali Linux on the internal drive (live 2026-11-04). An NVIDIA GPU is optional; the reference run used an RTX 2060 (about 6GB VRAM). The full guide is local-jarvis/README.md and the platform record is local-jarvis/PLATFORM-KALI.md. Router v2.2, the 50 second budget, the 60 second client wait, ComfyUI v0.43.0, and freellmapi are on the owner's laptop. freellmapi is the fallback only. REA 6.7.0 is ready for local app analysis.

  1. 1 Install the prerequisites

    Python 3.13, Ollama, and the two models named in the guide. VLC and Piper are in the same document. PipeWire audio routing and REA are optional. REA 6.7.0 is ready for local app analysis.

  2. 2 Run the installer

    From local-jarvis/:

    ./install.sh

    install.sh checks prerequisites, creates ~/Jarvis/venv, and installs both requirements files. It does not register autostart unless you pass --register-autostart.

  3. 3 Set secrets on the machine

    The repository ships placeholders only (CHANGE_ME, <user>). Set the VLC password and the user account locally. Do not commit them.

  4. 4 Start it yourself

    python3 ~/Jarvis/orchestrator.py, then open http://localhost:8080. The voice loop is a manual command. It is not a login item.

  5. 5 Enroll, then calibrate

    Five takes of the wake phrase. Treat 0.45 as a starting point. Score your own voice, your voice across the room, and an unknown voice before you change the number.
