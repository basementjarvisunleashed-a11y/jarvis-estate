# Code of Conduct

## Our standard

This project is a working estate, run in public. Participation — issues,
discussions, pull requests, wiki edits — is held to the standard the estate
holds itself to:

- **Truth over comfort.** Argue from evidence. Claims about the system are
  checked against the record, and corrections are made in the open.
- **Respect the operator's attention.** Be specific, be brief, cite the file
  or the fact. Signal over noise.
- **Assume good faith; verify anyway.** Disagreement is welcome and expected;
  personal attacks, harassment, and bad-faith disruption are not.
- **Stay inside the boundary.** No private information about any person —
  theirs or anyone else's — in any public space of this project. Ever.
- **Credit work.** Ideas and fixes are attributed to the people who brought
  them, in the release log.

## Enforcement

Conduct is moderated by the estate. Reports go to
**HgXengineering@gmail.com**. Consequences scale with the conduct: a private
note, a public correction, removal of content, or exclusion from the
project's spaces. Decisions are final and are not debated in the threads
they concern.

## Scope

This code applies in all of the project's public spaces: this repository,
its wiki, discussions, and the project's accounts when acting for the
project.
