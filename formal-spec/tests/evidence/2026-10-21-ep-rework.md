# Evidence-packet schema rework — 2026-10-21 (~12:46 ET)

On HgX's order, following his Q5/OQ-5 answer ("C.1 sketch names"). The v0.1 draft
`contracts/evidence-packet.schema.json` was reworked to Appendix C.1's field names.
The schema is a DRAFT — drafts may be edited. Ratified files (`contracts/events.md`,
the whitepaper) were NOT touched.

## What changed

Old draft fields (§6.6/events.md names):
`packet_id, work_id, revision (integer), created_at, artifact_refs[] (digest-bound),
source_observations[], test_results[], approval_refs[], gaps[] (required), checksum`.

New fields (Appendix C.1 sketch, exactly):
`packet_id, work_id, artifact_revision (string), created_at, approval_ref (optional),
checks[] (name, result: pass|fail, observed_at, detail), gaps[] (optional)`.
Required: `["packet_id", "work_id", "artifact_revision", "created_at", "checks"]`.
The sketch's `gaps` field IS present, so INV-E4's schema backing survives — but the
sketch lists it as optional, so INV-E4 enforcement moved from schema-required to
the packet guard (missing `gaps` is refused at guard level).

Also reworked: the fixture (`tests/layer1/fixtures/evidence-packet.valid.json`),
the `check_evidence_packet` guard, and the SCH-EP tests — now SCH-EP-01–06:
01 valid authorises; 02 missing required `checks` rejected (schema); 03 unknown
check-result enum rejected (schema); 04 missing gaps rejected (guard, INV-E4);
05 artifact_revision mismatch rejected (guard, INV-E2); 06 failed check rejected
(guard). Re-run: **25/25 schema tests pass** (was 23); all other schemas
(AI/DP/AM/WT) unchanged and green. Full log:
`tests/evidence/2026-10-21-schema-tests-v2.log`.

## Divergences (recorded, not silently fixed)

1. **events.md divergence:** ratified `contracts/events.md` event 6 still uses the
   §6.6 names. The schema and the ratified vocabulary now disagree on the packet's
   shape. A contract amendment to events.md needs HgX's word.
2. **Revision type tension:** the sketch types `artifact_revision` as a string;
   Q2 decided revision tokens are integer. The guard compares on the coerced
   string (`str(manifest.revision) == packet.artifact_revision`). Type coherence
   for the INV-E2 binding is an open question for HgX.
3. **Lost bindings:** the sketch carries no artifact digests, no `source_observations`,
   and no packet checksum. The digest cross-check of the earlier draft is gone —
   INV-E2's schema backing is now name+revision-string only, weaker than the
   digest-bound form it replaced.

## INV-E4 implication (one sentence)

INV-E4's schema backing is **preserved but relocated**: the sketch keeps a `gaps`
field (so nothing about omission visibility was lost), but lists it optional, so the
"missing gaps refuse completion" rule is now enforced by the packet guard rather
than the schema — the invariant holds, the layer moved.
